# SuperAgent 实时运行拓扑

页面打开后，架构图直接展示当前系统。左侧是虚拟 IM 和 GitHub，中间是 Router 与工单队列，右侧是按工单展开的 Worker、PR 和回到原会话的回复。两张工单并行时同时保留两条独立分支。即使一条分支已经交付，另一条分支仍按自己的状态更新。

## 图上的节点和连线

| 位置 | 图上显示 | 展开后显示 |
| --- | --- | --- |
| 来源 → Router | 来源、连接状态和新消息的流向 | 消息时间、系统接收时间、来源会话、摘要 |
| Router → 队列 | 收到、接受、归并、忽略 | Decision ID、准入结果和结构化原因、Router 决定时间 |
| 队列 → Worker | 排队或启动，每张工单一条执行分支 | Assignment ID、入队时间、派发时间、实际启动时间和排队耗时 |
| Worker → PR | 执行、空闲、等待人工、失败、报告就绪和关联 PR | 当前任务、可观测的操作摘要、报告与重试记录、PR 状态及链接 |
| Outbox → 原会话 | 回复等待投递、已发出、投递失败或目标失效 | 消息类型、目标会话、时间、重试和失败原因 |

Worker Session 实际创建或启动后才展示 Worker 节点。入队的任务留在队列，报告就绪与 PR 合并分别显示。点击节点或连线打开详情，原图保留在视野内。选中 PR 时高亮相关分支，其他运行中的分支仍可见。PR 是一条工单可能产生的交付物，回复可以先于 PR 出现，也可能独立完成。

## 事件、实时性与 PR 记录

1. 在 `Runtime` 接入已有的 Trigger、Gate、Decision、Ticket 和 Outbox 观察点。通过 `DshExecutor` 的 Session 状态和实际派发补齐 Worker 开始、空闲、失败等事件。工具执行首版只记录可识别的操作类型、结果和时间。比如工具确实开始运行测试，才显示「正在跑测试」。否则展示已知的工单标题与 Worker 状态。
2. 在现有 SQLite 中持久化白名单事件，字段包含单调递增序号、事件类型、发生时间、关联 ID 和可展示的摘要。业务事件和状态一起提交，提交后通知 SSE 读端。按 `triggerId → decisionId → ticketId → assignmentId` 串起因果。由既有 GitHub PR 归属逻辑产生关联事件，以 `repository + prNumber` 查阅原工单及相关 Assignment 的历史。PR 出现前的事件通过关联查询得到。多个 PR 共有的工单事件标记为工单级，CI 或审查结果只归入相应 PR。
3. 页面先读取同一一致性点上的状态和事件游标，再用 SSE 增量更新。断开后从最后确认的序号补齐，按序号去重。缺失或已清理的历史标记为不可用。GitHub 事件沿用现有轮询，区分外部发生时间和本机收到时间。观测页沿用管理端的本机访问和同源限制。

## 交付顺序

1. **只读预览。** 用当前部署的真实工单、运行状态和回复回执看版式及展开方式。预览每两秒读取管理 API 和只读 SQLite。Worker 的工具级进度、精确 PR 绑定时间和持久化事件流留给正式版。现有记录支持查询 Router 决定时间、Assignment 入队与启动时间。已经送达的虚拟 IM 回复按回执 ID 匹配聊天消息时间。
2. **接通正式事件流。** 在管理端增加观测快照与 SSE，给 Router 派发、Worker 状态、PR 绑定和回帖接入提交后的事件流。先跑通一个真正有 PR 的任务，再补齐并行、断线重连、重试、GitHub 评论回流和旧记录边界。
3. **用两个并发任务验收。** 两条分支同时出现，能分别展开查看 Router 决策、排队、实际启动和操作摘要。某一条先生成 PR 或先回复时，只更新它自己的分支。刷新后 PR 仍能查到绑定前的工单记录。再验证一张没有 PR 的工单和一次失败投递，检查图中状态和记录一致。

## 启动本机预览

先按根目录 README 启动虚拟 IM。在 PowerShell 运行下面的命令。预览和部署运行在同一 WSL Debian 中，SQLite 用只读方式打开。

```powershell
wsl -d Debian --exec /home/plankton/.local/share/superagent-virtual-im/node/bin/node /mnt/c/Projects/Agent/my-super-agent/dsh-superagent-prototype/scripts/observatory-preview/server.mjs
```

在浏览器打开 [实时运行拓扑](http://127.0.0.1:3083/)。点击节点或连线查阅详情，选择「近期完成」查看已经交付的分支。预览端口为本机的 `3083`，默认读取 `3082` 上的 SuperAgent。
